# AfricanAlkanesML

This repository contains the necessary data files and code for all dataset splitting, synthetic augmentation, and model training and validation. This repo is designed to accompany the publication:

Tweedy, R.R., Shi, S.C. & Uno, K.T. 2016. Supervised Machine Learning Approaches to African Plant Chemotaxonomy from n-Alkane Chain Length Abundances. Organic Geochemistry. DOI: [pending]
